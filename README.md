# Tee Vision — ホール3D距離ビュー

国土地理院の航空写真と数値標高モデル（DEM）から、ゴルフホールを3Dで表示するWebアプリです。距離・ハザード・フェアウェイ幅をPMI風の注釈で重ねて表示します。サーバ不要の `index.html` 1枚で動きます。

## 公開方法（GitHub Pages）

1. このリポジトリの **Settings → Pages** を開く
2. Source を `Deploy from a branch`、Branch を `main` / `/ (root)` にして保存
3. 数分後、`https://shi-soma.github.io/golf-cource-model/` で開けるようになります

位置情報（GPS）はHTTPSが必須なので、GitHub Pagesのまま使うのが簡単です。

## 使い方

### 事前準備（家で）
1. 地図でコースを表示する（住所検索の初期値はライオンズカントリー倶楽部）
2. ティーをタップし、続けてターゲット（グリーン中央やドッグレッグの角）をタップする
3. ホール名を付けて「保存」する。端末のブラウザに保存されます
4. 「URLコピー」でそのホールのリンクを共有できます。同伴者にもそのまま送れます

### コースで
- 「保存済みホール」から選んで「3Dで見る」
- または「現在地」でティーを今いる場所にし、ターゲットをタップして「3Dで見る」

### 3D画面
| 表示 | 内容 |
|---|---|
| 黄色の弧と `200y` | ティーからの等距離線（100〜300y） |
| `幅 32y` | 各距離でのフェアウェイ幅（航空写真から推定） |
| `右バンカー 182–201y` | ハザードの手前と奥（越え）までの距離 |
| 地形をタップ | ティーからの距離、残り距離、ラインからの左右ずれ、高低差 |
| 2点計測 | 任意の2点間の水平距離。自動推定を確かめるときに使う |
| 起伏×2 | 高さを2倍に強調し、うねりを見やすくする |
| 高低差 | 高低差の数値表示をオン/オフする |

## 仕組み

- **地形**：国土地理院の標高タイル。5mメッシュ（`dem5a_png`）を優先し、欠損部分は10mメッシュ（`dem_png`）で補完
- **テクスチャ**：国土地理院のシームレス空中写真（z18、約0.5m/px）
- **座標系**：ティーを原点、ターゲット方向を+Yとするローカル座標（m）
- **ハザード検出**：航空写真を1mセルに分け、色で分類（砂＝明るい黄白色、水＝暗い青系）。連結成分ごとに手前と奥の距離を計算
- **フェアウェイ幅**：緑のセルの明るさを大津の二値化で「明るい緑＝フェアウェイ」と「暗い緑＝ラフや林」に分け、ターゲットライン上の連続区間の長さを求める

## 限界と注意

- ハザードとフェアウェイ幅は色による**目安**です。航空写真の撮影時期、影、カート道、芝の状態で誤検出することがあります
- 航空写真や標高データは撮影・測量時点のもので、コース改修は反映されていない場合があります
- 競技でのご利用について：距離計測機器はローカルルールで認められることが多いですが、**高低差の情報は競技では使用できません**。競技中は「高低差」をオフにしてください。プレーの進行を妨げないようご注意ください
